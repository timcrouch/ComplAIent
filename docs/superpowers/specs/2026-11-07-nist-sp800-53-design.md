# NIST SP 800-53 Rev. 5 in the control library — design

Date: 2026-11-07. Issue #20. Plan: `docs/superpowers/plans/2026-11-07-plan-12-nist-sp800-53.md`.

## Problem

Clients with US federal, government-contractor or FedRAMP exposure are asked about NIST SP 800-53, the detailed US control catalogue. NIST CSF 2.0 (Plan 10) covers outcomes; auditors of these clients want the 800-53 controls themselves.

## Decisions

1. **Scope: the SP 800-53B Moderate baseline, base controls only.** That is 177 controls in 18 families. Enhancements (110 more in Moderate) and the Low and High baselines are left for a later issue. Moderate is the common choice for contractors and FedRAMP.
2. **One framework, one version.** Key `nist-sp800-53`, name `NIST SP 800-53`, publisher `NIST`, version key `nist-sp800-53-r5`, label `Rev. 5 (Moderate baseline)`. Refs use the official form (`AC-2`, `SC-7`), in catalogue order.
3. **Own-words titles**, the same rules as CSF: one sentence, capital to full stop, 5 to 16 words, not NIST's sentence lightly edited. No official control text ships in `fullText`; importing it stays a separate decision (ADR-0008).
4. **Mapped through our controls only.** Each of the 177 is mapped to at least one library control. One control is added, ACC-10 (end idle or finished sessions), for session termination (AC-12), which nothing covered. No CSF ↔ 800-53 cross-mappings and no NIST OLIR import: the library links frameworks only through its own controls. Mappings ship unreviewed.
5. **Grouped by family** in the SoA, using the library grouping contract of issue #19: one level of `groups` (the 18 families, official family names as titles), and a `group` on every requirement.
6. **Mappings in their own file.** About 200 extra mappings would push some control files past the 500-line limit. The SP 800-53 mappings to existing controls live in one mapping file named by the manifest, and the loader merges them into the controls, so everything after loading (validation, sync, the app) sees the usual shape. The framework file stays one file: with one requirement per line (Plan 11 formatting) it is about 220 lines.

## Effect on the product

Almost all data. Setup, the library filter, the SoA and the AI framework suggestion read frameworks from the synced library, so SP 800-53 appears in all of them after `pnpm db:seed`. One small API change: the Excel SoA export calls its group column "Family" for SP 800-53 (the #19 level-name map). No web, database schema or migration change.

## Out of scope

Enhancements; Low and High baselines; the privacy baseline (PT family) and the PM family, which are not in the Moderate security baseline; official text; OLIR mappings; changes to the AI mock or the demo company.
